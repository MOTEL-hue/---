# מעצב אימיילים אוטומטי ל-Gmail

תוסף לדפדפן שמוסיף לחלון כתיבת מייל ב-Gmail כפתור ✨: לחיצה עליו מעצבת ומסדרת את המייל בעזרת Gemini
(תיקון שגיאות, הדגשות, פסקאות), בלי לגעת בקישורים ובתמונות.

## התקנה

1. מתקינים בדפדפן את התוסף **Tampermonkey** (מחנות התוספים של Chrome, Edge או Firefox).
2. פותחים את הקובץ [`gmail-formatter.user.js`](gmail-formatter.user.js), לוחצים **Raw**, ו-Tampermonkey מציע להתקין - מאשרים.
3. נכנסים ל-Gmail ופותחים "כתיבה". ליד כפתורי העיצוב מופיעים ✨ ו-▾.

## הגדרה ראשונה

1. מקבלים מפתח Gemini חינמי ב-[Google AI Studio](https://aistudio.google.com/app/apikey).
2. ב-Gmail לוחצים על ▾ ליד ✨, מדביקים את המפתח ובוחרים סגנון:
   - **שמרני** - רק תיקונים וסידור.
   - **שיווקי** - כותרות בולטות וניסוח מזמין.
   - **משוחרר** - יותר חופש בניסוח.
3. לוחצים "שמור הגדרות". המפתח נשמר רק בדפדפן שלכם.

## שימוש

- כותבים את המייל ולוחצים ✨. אחרי כמה שניות המייל מעוצב.
- לא אהבתם? לוחצים **↶** (מופיע אחרי העיצוב) וחוזרים לטקסט המקורי.

## פרטיות ואבטחה

- תוכן המייל נשלח ל-Gemini של Google לצורך העיצוב בלבד.
- התוצאה מנוקה מכל קוד לפני שהיא נכנסת למייל.
